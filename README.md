# Xrust

Ранее проект назывался Rust X. Переименование касается репозитория и
отображаемого имени. Для совместимости с установленными версиями Forkop
сохранены пакет и Cargo feature `rust-x`, теги `rust-x-v*`, пути установки,
формат версии executable и канал обновлений `/forkop/rust-x/` на зеркале.

Изменения upstream перенесены выборочно; сокращённый
профиль пакетов описан в [docs/RUST-X.md](docs/RUST-X.md). Обычная Cargo-сборка
включает сохранённые протоколы апстрима; пакеты Forkop собираются явно с
`--no-default-features --features rust-x`. Числа и возможности в
унаследованной документации ниже относятся к upstream, если не указано иначе.

Поддерживаемые платформы: **OpenWrt x86_64 и aarch64_cortex-a53**.
CI выполняет Linux-тесты и статические musl-сборки этих двух архитектур.
Другие ОС и архитектуры не входят в поддержку нашего форка.
