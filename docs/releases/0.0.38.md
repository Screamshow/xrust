## Hysteria 2

- Повышена скорость передачи и снижено потребление CPU при включенном Salamander.

## VLESS и Vision

- Снижено потребление CPU при загрузке.

## WireGuard и AmneziaWG

- Сокращено копирование пакетов и добавлено переиспользование буферов.
- Добавлена пакетная отправка UDP через GSO для датаграмм одинакового размера.
- Ускорено обновление приёмного TCP-окна после чтения данных из туннеля.
- Приёмный TCP-буфер увеличен с 64 до 128 КиБ для повышения скорости загрузки.
