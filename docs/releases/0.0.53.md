## Транспорты

- Буферы HTTP/2 теперь растут по мере нагрузки и освобождают лишнюю память в простое.
- Снижено потребление памяти в XHTTP, WebSocket, Tailscale и MASQUE.

## DNS и маршрутизация

- Кэши DNS и FakeIP теперь выделяют память по мере заполнения.
- Снижено потребление памяти при загрузке и индексации наборов правил SRS.
- Кэш удалённого набора правил остаётся доступен офлайн при повреждении только метки времени.

## Пакеты для OpenWrt

- Уменьшен размер бинарника Xrust и пакетов APK и IPK.
