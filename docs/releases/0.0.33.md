## Соединения и протоколы

- Исправлена проверка диапазона длины идентификатора сессии XHTTP. Теперь учитываются все длины в заданном диапазоне, а не только минимальная.
- Устранено ошибочное отклонение допустимых конфигураций XHTTP, включая сочетание алфавита Base62 и длины `4-8`.
- В расширенное распознавание BitTorrent добавлены HTTP-запросы к источникам HTTP seed по BEP 17.
- Список распознаваемых User-Agent торрент-клиентов расширен с 6 до 33 названий, включая BiglyBT, BitComet, LibreTorrent, TorrServer, Flud и WebTorrent.

## Обработка трафика

- Уточнена проверка HTTP-запросов перед распознаванием BitTorrent. Некорректная строка запроса больше не создаёт исключение маршрутизации по User-Agent.
- Для HTTP seed проверяются длина и кодирование `info_hash`, корректность номера части и отсутствие повторяющихся обязательных параметров.
- Названия торрент-клиентов распознаются в начале User-Agent с проверкой границы имени. Произвольное упоминание названия внутри браузерного User-Agent не считается признаком BitTorrent.
- Сохранены обработка TCP-запросов, разделённых между несколькими чтениями, и передача прочитанных данных без изменений.
- При выключенном расширенном распознавании сохранено прежнее поведение анализаторов протоколов.

## Ограничения

- Зашифрованный BitTorrent MSE/PE и содержимое HTTPS не распознаются этим механизмом.
- HTTP-запросы, определённые по User-Agent торрент-клиента, могут включать его сопутствующие обращения
