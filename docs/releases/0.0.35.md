## Соединения

- Исправлено подключение к REALITY-серверам, отклоняющим рукопожатие без гибридной группы X25519MLKEM768. Ранее рабочий ключ мог завершаться ошибкой `the certificate carries no Ed25519 key`.
- REALITY по умолчанию сохраняет группы обмена ключами выбранного браузерного профиля вместо принудительного удаления X25519MLKEM768.
