## Соединения и протоколы

- Возвращена поддержка клиента Trojan с TCP и UDP, TLS, REALITY, WebSocket и gRPC.
- Для VLESS и Trojan заголовок запроса передаётся вместе с первыми данными. Исправлена передача VLESS через XHTTP.
- Для gRPC и HTTP/2 добавлено совместное использование соединений несколькими туннелями.
- Исправлена совместимость HTTPUpgrade с серверами sing-box.
- Исправлены завершение передачи после закрытия одного направления и освобождение зависших соединений.
- Для исходящих TCP-соединений включён keep-alive.
- Исправлены зависания WireGuard и AmneziaWG при заполнении буферов и возобновление передачи после освобождения места.
- Для WireGuard и QUIC увеличены доступные буферы сокетов. Отправка пакетов WireGuard выполняется группами.
- Для отправки данных Hysteria2 добавлено управление скоростью Brutal при заданном up_mbps.

## TLS и сетевые транспорты

- Обновлены ClientHello, GREASE, ALPN и поведение TLS для поддерживаемых браузерных профилей.
- Профиль random использует firefox. Неподдерживаемые android, 360 и qq отклоняются при проверке конфигурации.
- Обновлены заголовки WebSocket и HTTPUpgrade, параметры HTTP/2 и gRPC, порядок заголовков и поведение XHTTP по образцам эталонных клиентов.
- Исправлена совместная отправка WebSocket early data и запроса переключения протокола.
- Обновлены размеры TLS-записей, начальных QUIC-пакетов и транспортные параметры QUIC. В QUIC предлагается гибридная группа X25519MLKEM768.
- Исправлена обработка TLS close_notify и закрытие TLS-соединений.
- Исправлена проверка серверной конфигурации REALITY без отдельного сертификата.

## Горячая перезагрузка и наборы правил

- Неизменённые наборы правил сохраняются при горячей перезагрузке без повторной загрузки и разбора.
- Планирование перезагрузки может использовать сведения о наборах правил работающего ядра.
- Отказ в применении конфигурации отражается в состоянии применённой конфигурации.

## Проверка задержки

- При неудачной проверке задержки Clash API возвращает причину ошибки подключения, TLS или получения ответа.

## Tailscale

- Уменьшена фоновая активность при отсутствии трафика и ограничена очередь исходящих данных.
- Исправлены повторные подключения к управляющему серверу и DERP без частых циклов повторов.
- При потере связи с управляющим сервером сохраняется последняя рабочая карта сети.
- Повторное рукопожатие WireGuard использует новый запрос.
- Проверки возможностей выполняются при изменении входных данных. Удалены параметры, которые ядро не применяло.

## Память и производительность

- Уменьшен размер выпускных сборок с сохранением оптимизаций криптографии.
- Добавлено повторное использование буферов TLS и WebSocket при простое и закрытии соединений. Буферы TLS также возвращаются в пул при переходе в Vision Direct.
- Убраны лишние копирования при чтении XHTTP и обработке UDP.
- Для Vision Direct добавлена передача загрузки средствами ядра Linux.
- Оптимизированы AES-GCM, ChaCha20-Poly1305 и обработка пакетов WireGuard.

## Сборки и совместимость

- Добавлены пакеты OpenWrt для ARM64 Cortex-A73.
