## Сборки и совместимость

- Добавлены пакеты OpenWrt APK и IPK для `aarch64_generic`, включая устройства на Rockchip RK3528A, RK3566, RK3576 и RK3588 с 64-битной прошивкой.
- Для новой архитектуры используется общая сборка ARM64. Сохранены пакеты Cortex-A53, Cortex-A73 и x86_64.
- Добавлены пакеты APK и IPK для `mipsel_24kc`, включая MediaTek MT7628AN. Сборка использует MIPS32r2 и soft-float без требования FPU.
- Устранена зависимость от аппаратных 64-битных атомарных операций на 32-битных процессорах.
- Запуск MIPS и передача данных проверены в эмуляции CPU 24Kc. Проверка на самих устройствах Rockchip и MT7628AN пока не проводилась; для установки нужен достаточный объём свободной flash и RAM.

## Установка и обновление

- Пакеты `aarch64_generic` и `mipsel_24kc` поддерживаются установщиком и выбором версии Xrust в Forkop X 2.6.0.
- Новые пакеты включены в проверку архитектур, подпись APK и каталог зеркала. Сохранена совместимость с предыдущими выпусками.
- Системные библиотеки MIPS и модули ядра используются из репозиториев установленной прошивки.
