## Сборки и совместимость

- Добавлены пакеты OpenWrt APK и IPK для `aarch64_generic`, включая устройства на Rockchip RK3528A, RK3566, RK3576 и RK3588 с 64-битной прошивкой.
- Для новой архитектуры используется общая сборка ARM64. Сохранены пакеты Cortex-A53, Cortex-A73 и x86_64.
- Пакеты для Rockchip собраны и проверены. Проверка запуска на самих устройствах пока не проводилась.

## Установка и обновление

- Пакеты `aarch64_generic` поддерживаются установщиком и выбором версии Xrust в Forkop X 2.6.0.
- Новые пакеты включены в проверку архитектур, подпись APK и каталог зеркала. Сохранена совместимость с предыдущими выпусками.
