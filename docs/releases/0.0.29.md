# Xrust 0.0.29 — draft for discussion

This description has not been approved for publication.

Adds OpenWrt APK and IPK packages for `aarch64_generic`, used by
`rockchip/armv8`. They use the same generic ARM64 executable as the existing
Cortex-A53 and Cortex-A73 packages. Existing package architectures remain
available; older published packages are unchanged.

The package validation, signing finalizer and mirror publisher accept the
additional complete APK/IPK pair while retaining historical release formats.
Forkop X 2.6.0 can select this architecture for installation and version changes.
On `aarch64_generic`, the version list includes only releases that actually
contain a matching package. Older Cortex-A53 packages are not forced onto it.

Validation results will be recorded in the preparation report before this
description is discussed. No Rockchip device is available for hardware tests;
package and installer checks do not establish on-device traffic compatibility.
