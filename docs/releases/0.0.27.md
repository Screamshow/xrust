## Безопасность

- Усилена проверка подлинности серверов REALITY и сертификатов при загрузке наборов правил и внешнего интерфейса. Закреплённые сертификаты проверяются и при включённом `insecure`.
- Обновлены TLS-зависимости и корневые сертификаты, ограничена распаковка сжатых сертификатов.
- Исправлены обработка некорректных URL в Clash API и разбор HTTP-ответов с ошибочными размерами или слишком большими телами.
- Усилена проверка SRS, TSRS и `cache.db`: повреждённые структуры отклоняются, ограничены размеры и глубина обработки. Загрузка TSRS из сети запрещена.

## DNS и FakeIP

- Ответы DNS проверяются на соответствие запросу.
- Одинаковые одновременные DNS-запросы используют один исходящий обмен. Усечённые UDP-ответы повторяются по TCP, а ответы из кэша возвращают оставшийся TTL.
- Ограничено количество одновременно обрабатываемых перехваченных DNS-запросов.
- Исправлено сохранение FakeIP при горячей перезагрузке конфигурации.

## Соединения и протоколы

- Исправлены завершение сессий XHTTP packet-up, зависания при закрытии передачи и обнаружение неработающих HTTP/2-соединений.
- Режим XHTTP `auto` с REALITY выбирает `stream-one`.
- Исправлены запуск Hysteria2 с одним `server_ports`, сохранение соединения при смене портов и очистка завершённых UDP-сессий.
- Исправлены кодирование и имя заголовка WebSocket early data.
- Исправлено чтение порта в SOCKS5 UDP-пакетах с доменным адресом.
- Устранено повторное открытие одного UDP-потока при поступлении пачки пакетов.
- Для входящих клиентских TCP-соединений включён keep-alive, предотвращены TProxy-соединения к самому перехватывающему слушателю.
- Неподдерживаемый VLESS Encryption отклоняется при проверке конфигурации.

## Наборы правил и кэш

- Добавлена обработка `domain_regex` в наборах правил, включая Go-последовательности `\Q…\E`.
- Ошибка обновления набора правил сохраняет рабочий TSRS-кэш.
- Уменьшено пиковое потребление памяти при загрузке SRS и записи `cache.db`.
- Усилена надёжность атомарной записи `cache.db`, при чтении выбирается актуальная метастраница.
- Кэш наборов правил перенесён в `/tmp/xrust-rulesets`.

## Clash API и TLS

- Исправлено восстановление сохранённого режима Clash без взаимной блокировки.
- Clash API продолжает принимать подключения после ошибок и закрывает молчащие клиенты по тайм-ауту.
- Запрос задержек группы возвращает соответствие участников и их задержек.
- ECH GREASE формируется заново для каждого ClientHello.
- Добавлена поддержка уровня журналирования `panic`.
