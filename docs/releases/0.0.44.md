## VLESS, XUDP и Vision

- Исправлены открытие UDP-сессий в режиме PacketAddr и обработка пустых датаграмм и кадров XUDP `Keep` и `End`.
- UDP-сессии восстанавливаются после закрытия туннеля, в том числе после перезапуска Xray.
- В Vision исправлена обработка коротких ответов и обрезанных кадров.

## WebSocket и gRPC

- Клиенты VLESS и Trojan поддерживают ранние данные в пути запроса WebSocket.
- Клиент gRPC учитывает настройки keepalive. Добавлена поддержка режима `multi` с пользовательскими путями методов и исправлена потеря данных при чтении ответов.
- Клиент gRPC сообщает об ошибках из `grpc-status` и об обрезанных сообщениях.

## XHTTP и TLS

- XHTTP поддерживает отдельные адреса отправки и загрузки с независимыми настройками TLS и REALITY.
- При закрытии по таймауту простоя уже полученные данные остаются доступны для чтения.
- Для XHTTP поверх HTTP/1.1 исправлены обработка промежуточных ответов, завершение потоков и повторное использование соединений.
- В `packet-up` исправлена отправка данных через `Cookie`. Ошибки отправки сохраняются для последующих операций записи.
- Добавлена проверка пинов сертификата и ЦС по правилам Xray. Параметр `vcn` задаёт имя для проверки сертификата отдельно от SNI.

## Hysteria2

- Исправлено распределение UDP-ответов между сессиями одного QUIC-соединения.
- UDP-сессии восстанавливаются после закрытия QUIC. Если открыть дополнительное соединение не удаётся, используется действующее.
- Максимальный размер полезной нагрузки UDP увеличен с 4 096 до 65 507 байт.

## WireGuard, AmneziaWG, MASQUE

- AmneziaWG адаптирует очередь отправки TCP к активности приёма. На Linux пакетная отправка UDP через GSO может включать короткую датаграмму в конце пакета.
- В MASQUE исправлены одностороннее закрытие TCP и освобождение ресурсов при отмене подключения.
