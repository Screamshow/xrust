## XHTTP

- Добавлена поддержка XHTTP поверх HTTP/3 с TLS 1.3 и настройками QUIC.
- Улучшена совместимость с Xray при работе HTTP/2 поверх REALITY, повторном использовании соединений через XMUX и обработке gzip-ответов.
- В режиме `packet-up` следующий POST может отправляться до получения ответа на предыдущий.
