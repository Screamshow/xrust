## Пакеты для Forkop 3

- Нативный бинарник устанавливается как `/usr/bin/xrust`. Forkop выбирает точную версию из своего манифеста.
- Профиль OpenWrt сохраняет локальные входы, прозрачный прокси, SRS, Clash API и клиентские транспорты. Серверные входы остаются в сборке с полным набором возможностей Cargo.
- Команда `/usr/bin/sing-box version` сохраняется для шага совместимости в обновляторе Forkop 2.7.6. Для отката на 2.7.6 используется архив Xrust 0.0.44.

## Соединения

- Уточнены адаптация TCP-окон и отправка UDP-пакетов AmneziaWG, обработка пакетов MASQUE и закрытие потоков.
