## Пакеты для Forkop X 3.0+

- Пакеты APK и IPK устанавливают ядро в `/usr/bin/xrust`.
- Из итоговой сборки убраны серверные инбаунды

## WireGuard и AmneziaWG

- Сокращено число копирований при чтении TCP в WireGuard и AmneziaWG и при отправке TCP в AmneziaWG.
- В AmneziaWG рост окна приёма TCP ограничен 1 МиБ при измеренном RTT до 8 мс.

## MASQUE

- Входящие датаграммы HTTP/3 обрабатываются группами, а в стандартном профиле увеличены буферы датаграмм.
- Исправлена обработка таймеров TCP в простое и отправка данных после подтверждений.
